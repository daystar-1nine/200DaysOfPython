## 📌 About the Journey

The **200 Days of Python + Data Science** repository is more than just a collection of tutorials. It is a systematic, highly structured engineering marathon designed to bridge the gap between basic syntax and production-grade artificial intelligence.

The core philosophy driving this journey:
1. **Engineering Over Scripting:** Writing clean, testable, and maintainable Object-Oriented code from day one.
2. **Theory Meets Practice:** Every statistical formula or ML algorithm is implemented practically—not just read about.
3. **Professional Tooling:** Heavy emphasis on Pytest, Git, virtual environments, Logging, and GitHub CI architecture.
4. **Iterative Complexity:** Starting from primitive `print()` statements and gradually scaling into PostgreSQL-backed FastAPI servers, advanced Pandas aggregations, Gradient Boosting ensembles, and Convolutional Neural Networks.

By documenting this journey daily, the objective is to cultivate deep technical communication skills alongside hardcore programming and data science capabilities.

### Phase 1 — Python Fundamentals (Days 1-30)
**Focus:** The bedrock of software engineering.
**Skills:** Data types, Loops, Functions, OOP, Exception Handling, File I/O, SQLite, basic Pytest.
**Outcome:** Capable of writing CLI applications, understanding class inheritance, and persisting data to local relational databases.

### Phase 2 — Intermediate / Professional Python (Days 31-40)
**Focus:** Advanced Pythonic paradigms.
**Skills:** Dunder methods, Decorators, Generators, Context Managers, Protocols, Dataclasses.
**Outcome:** Capable of writing highly memory-efficient, pythonic code that utilizes lazy evaluation and structural subtyping.

### Phase 3 — Backend & APIs (Days 41-50)
**Focus:** Serving software to the web.
**Skills:** FastAPI, Dependency Injection, SQLAlchemy ORM, Alembic Migrations, JWT Auth.
**Outcome:** Capable of deploying secure, transactional backend microservices backed by PostgreSQL.

### Phase 4 — Data Processing & Numerical Computing (Days 51-60)
**Focus:** High-performance tabular data.
**Skills:** NumPy (Broadcasting, Linear Algebra), Pandas (Series, DataFrames, Cleaning, Groupby).
**Outcome:** Capable of transforming raw, messy datasets into structured, analytical inputs using vectorized operations.

### Phase 5 — Data Visualization & Statistics (Days 61-70)
**Focus:** The math behind the machine.
**Skills:** Matplotlib, Seaborn, Probability distributions, Central Limit Theorem, Hypothesis Testing, A/B Testing.
**Outcome:** Capable of extracting statistical significance from data and communicating it visually.

### Phase 6 — Classical Machine Learning (Days 71-80)
**Focus:** Predictive modeling foundations.
**Skills:** Linear/Logistic Regression, Cross-Validation, Regularization, Precision/Recall optimization.
**Outcome:** Capable of building and evaluating baseline predictive engines (e.g., Customer Churn pipelines).

### Phase 7 — Advanced Machine Learning (Days 81-86)
**Focus:** Winning Kaggle competitions.
**Skills:** Gradient Boosting, XGBoost, LightGBM, SVMs, Naive Bayes.
**Outcome:** Capable of deploying non-linear, tree-based ensemble models for massive tabular datasets.

### Phase 8 — Deep Learning & Computer Vision (Days 87-90)
**Focus:** Spatial pattern recognition.
**Skills:** Artificial Neural Networks, Backpropagation, CNNs, Dropout, Batch Normalization, Data Augmentation.
**Outcome:** Capable of building computer vision pipelines utilizing TensorFlow/Keras architecture.
