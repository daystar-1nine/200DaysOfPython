# Day 83: LightGBM, CatBoost & Modern Boosting

Welcome to Day 83! Today we explore **LightGBM**, **CatBoost**, and benchmark them against XGBoost and Random Forest.

## What's Inside?
- `app/`: Modular ML pipeline including data processing, multiple models, and evaluation.
- `data/`: The customer churn dataset.
- `output/charts/`: 20+ analytical visualizations generated by the pipeline.
- `tests/`: Pytest suite covering the pipeline.
- `coding_challenges/`: Challenges to reinforce the concepts.
- `Day83.md`: Masterclass covering interview Q&As on LightGBM & CatBoost.

## How to Run
```bash
cd "Day 83"
python -m app.main
pytest tests/
```
