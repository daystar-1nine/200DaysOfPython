# Day 87: Neural Networks Fundamentals

Welcome to Day 87! Today we cross into **Deep Learning** by understanding Artificial Neurons, Activation Functions, Forward Propagation, and Gradient Descent.

## What's Inside?
- `app/`: Neural Network pipeline via TensorFlow/Keras compared with Logistic Regression baseline.
- `data/`: Customer churn dataset.
- `output/charts/`: 18+ analytical visualizations plotting NN validation loss and ROC-AUC.
- `tests/`: Pytest suite to confirm graph operations and data flow.
- `coding_challenges/`: Pure NumPy experiments from scratch representing neurons and gradients.
- `Day87.md`: Masterclass notes on Epochs, Batches, Backpropagation, and Overfitting.
