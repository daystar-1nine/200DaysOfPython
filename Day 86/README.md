# Day 86: Support Vector Machines (SVM)

Welcome to Day 86! Today we explore **Support Vector Machines (SVM)** and Maximum Margin classification.

## What's Inside?
- `app/`: ML pipeline running Linear, Polynomial, and RBF kernels for SVM.
- `data/`: Customer churn dataset.
- `output/charts/`: 16+ analytical visualizations mapping SVM decision boundaries.
- `tests/`: Pytest suite covering the SVM pipelines.
- `coding_challenges/`: Challenges around decision boundaries, C, and Gamma scaling.
- `Day86.md`: Masterclass notes on Hyperplanes, Support Vectors, and the Kernel Trick.

## How to Run

cd "Day 86"
python -m app.main
