# Day 85: Naive Bayes & Probabilistic Classification

Welcome to Day 85! Today we explore **Naive Bayes** and probabilisitic ML.

## What's Inside?
- `app/`: Dual ML pipelines (Part A: Gaussian NB for Churn, Part B: Multinomial NB for Text).
- `data/`: Customer churn dataset and support messages dataset.
- `output/charts/`: 15+ analytical visualizations.
- `tests/`: Pytest suite covering the probabilistic pipelines.
- `coding_challenges/`: Challenges to reinforce the concepts of Bayes Theorem.
- `Day85.md`: Masterclass notes on Laplace Smoothing, Conditional Independence, and TF-IDF.

## How to Run
```bash
cd "Day 85"
python -m app.main
pytest tests/
```
