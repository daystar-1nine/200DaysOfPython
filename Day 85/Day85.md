# 🚀 DAY 85 / 200 — NAIVE BAYES & PROBABILISTIC CLASSIFICATION

## 🧠 Masterclass: Interview Q&A on Naive Bayes

### Fundamentals
1. **What is Naive Bayes?**
   Naive Bayes is a probabilistic classifier based on Bayes' Theorem, with strong (naive) independence assumptions between features.
2. **Why is it called 'Naive'?**
   It assumes that all features are conditionally independent given the class, which is rarely true in the real world (e.g. 'free' and 'money' in a spam email).

### Preprocessing and Variants
3. **What is GaussianNB used for?**
   It assumes continuous data follows a normal (Gaussian) distribution, used for numerical features like income, age, or tenure.
4. **What is MultinomialNB used for?**
   It assumes data follows a multinomial distribution, commonly used for discrete counts like word frequencies (TF-IDF) in text classification.
