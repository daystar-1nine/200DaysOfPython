# Day 29: Professional Testing with Pytest

A comprehensive unit, integration, fixture, parameterization, and mocking test suite for Python applications.

## Test Execution Commands

```bash
# 1. Run all Pytest test suites
pytest -v

# 2. Run specific Unit or Integration test directories
pytest Day\ 29/expense_tracker_pytest/tests/unit/
pytest Day\ 29/expense_tracker_pytest/tests/integration/
pytest Day\ 29/api_client_pytest/

# 3. Code Coverage Report
pytest --cov=expense_tracker
```
