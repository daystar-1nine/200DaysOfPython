# 🌤️ Weather Dashboard

A professional CLI application with isolated configuration management using `.env` and modular weather fetching services.

## 🚀 Setup & Execution

1. **Create Virtual Environment:**
   ```bash
   python -m venv venv
   ```
2. **Activate Environment:**
   - Windows: `venv\Scripts\activate`
   - Linux/macOS: `source venv/bin/activate`
3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Configure Secrets:**
   Update `.env` file with your `WEATHER_API_KEY`.
5. **Run Application:**
   ```bash
   python app.py
   ```
