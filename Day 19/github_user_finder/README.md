# 🔍 GitHub User Finder

A professional CLI application that searches and fetches profile details from the GitHub REST API.

## 🚀 Setup & Execution

1. **Create Virtual Environment:**
   ```bash
   python -m venv venv
   ```
2. **Activate Virtual Environment:**
   - Windows: `venv\Scripts\activate`
   - Linux/macOS: `source venv/bin/activate`
3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Run Application:**
   ```bash
   python app.py
   ```
