# Day 84: K-Nearest Neighbors (KNN)

Welcome to Day 84! Today we explore **K-Nearest Neighbors (KNN)**, a powerful distance-based ML model.

## What's Inside?
- `app/`: ML pipeline with StandardScaler implementation for distance-based learning.
- `data/`: Customer churn dataset.
- `output/charts/`: 12+ analytical visualizations (including PCA boundaries).
- `tests/`: Pytest suite covering the pipeline.
- `coding_challenges/`: Challenges to reinforce the concepts of Euclidean and Manhattan distance.
- `Day84.md`: Masterclass notes on the Curse of Dimensionality and Feature Scaling.

## How to Run
```bash
cd "Day 84"
python -m app.main
pytest tests/
```
