# 🚀 DAY 84 / 200 — K-NEAREST NEIGHBORS (KNN)

## 🧠 Masterclass: Interview Q&A on KNN

### Fundamentals
1. **What is KNN?**
   KNN is a supervised ML algorithm that makes predictions based on the 'K' most similar instances in the training data.
2. **Why is it a Lazy Learner?**
   Because it doesn't learn a discriminative function during training. Instead, it memorizes the dataset and performs computation only when predicting.

### Preprocessing
3. **Why is feature scaling critical for KNN?**
   Since KNN uses distance metrics (like Euclidean), features with large numerical ranges (e.g., income) will artificially dominate the distance calculation compared to features with small ranges (e.g., age). Scaling ensures equal contribution.
